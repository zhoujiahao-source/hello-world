## 基于网格地图的人工生命生态系统设计

本文档概述一个用于科研模拟的人工生命系统设计，涵盖基因编码、演化逻辑、环境与资源流动、可视化层设计，以及便于实验拓展的模块化架构。

### 1. 生物基因编码
- **基因表示**：使用定长/变长 bitstring 或简化的指令序列（字节码）。基因由多个功能段组成：感知参数（视野半径、感受器灵敏度）、行为策略（移动/觅食/攻击/繁殖优先级）、代谢效率、形态特征（体型、速度成本）、交互特性（合作倾向）。
- **表达与表型映射**：基因段通过查表或小型 MLP（权重由基因编码）映射到行动策略参数；允许冗余编码以增强鲁棒性。
- **基因约束**：对关键参数设定上下限、归一化/softmax 处理，防止异常行为或数值爆炸。

### 2. 演化逻辑
- **复制**：繁殖消耗能量和时间，父代将基因复制给子代，可选双亲重组（单点/双点交叉）。
- **突变**：按位翻转/高斯扰动，突变率可随环境压力或种群密度自适应调整；支持热区突变（行为策略段更高概率）。
- **选择**：基于能量累积、寿命、生殖成功率、资源占用效率等适应度指标；可配置软选择（轮盘赌）或硬淘汰（阈值裁剪）。
- **生态平衡机制**：增加拥挤惩罚和资源再生延迟，避免单一策略垄断；引入“灾变”事件测试种群恢复力。

### 3. 环境与资源流动
- **网格世界**：二维离散网格，周期性边界或封闭边界可配置。每个网格单元存储资源量、地形类型、占据状态、环境变量（温度、湿度、毒性）。
- **资源循环**：
  - **生成**：按地形类型和时间步进行再生，支持季节性波动（正弦/分段函数）。
  - **流动**：扩散模型或定向流（如河流/风）在邻接格传递资源；可设衰减系数。
  - **消耗与腐殖**：生物摄取资源获得能量；死亡个体形成腐殖质，缓慢转化为基础资源。
- **事件系统**：随机或脚本化事件（干旱、丰年、毒雾、捕食者迁入）改变局部或全局资源，测试策略稳健性。

### 4. 网格地图可视化层设计
- **渲染层次**：
  - 底层：地形与资源热力图（颜色映射资源密度/地形类型）。
  - 中层：生物实体图层，基于体型/能量/类型的尺寸与颜色编码。
  - 叠加层：视野范围、路径轨迹、交互事件（攻击/交配）提示，统计 overlay（种群数量、平均适应度）。
- **交互要点**：支持时间步播放/暂停/快进、视角缩放、鼠标 hover 显示单元格/个体状态，过滤特定基因型或族群。
- **性能优化**：使用增量渲染或脏矩形更新，避免全图重绘；大规模时提供采样显示或矢量化批绘制。

### 5. 科研拓展的模块化架构
- **核心模块**：
  - `GridWorld`：存储网格、地形、资源与环境变量；提供扩散与再生算子。
  - `Organism`：封装基因、表型状态、能量收支、生命周期钩子。
  - `EvolutionEngine`：管理繁殖、突变、选择与适应度计算。
  - `Scheduler`：调度时间步、事件触发、并行批处理。
  - `Metrics & Logging`：采集多尺度数据（个体、族群、环境），输出 CSV/Parquet/JSONL；可插拔指标管线（如香农多样性、网络中心性）。
- **可插拔策略接口**：
  - 感知-决策策略：规则表、行为树、强化学习策略均可注入，实现统一的 `act(observation)` 接口。
  - 资源再生与流动：不同地形和季节模型通过策略模式注册。
  - 事件脚本：基于配置文件或 Python/Lua 回调，便于实验编排。
- **实验控制**：集中配置（YAML/JSON）定义随机种子、网格尺寸、资源初值、突变率、选择方式；支持批量实验和可重复性。
- **数据采集与可视化**：运行中实时指标流（WebSocket/文件），实验后分析脚本生成统计图；关键状态快照（基因分布、热力图）可回放。

### 6. 参考数据流程（科研版）
1. 初始化网格与地形 → 资源初始分布生成。
2. 种群播种（随机/预设基因型）。
3. 循环时间步：
   - 环境更新（资源再生/扩散、事件执行）。
   - 个体感知 → 决策 → 行为执行（移动/觅食/交互/繁殖）。
   - 能量与寿命结算，死亡与腐殖回流。
   - 演化算子（选择、复制、突变、重组）。
   - 指标记录与可视化刷新。
4. 结束条件：达到步数上限、资源耗尽、或种群灭绝；输出完整日志与快照。

### 7. 快速实验配置示例（摘要）
- **网格**：128×128，周期性边界；草地/水域/高地三类地形。
- **资源**：草地高再生，水域低可用度但高扩散，高地低再生且高衰减。
- **突变率**：基础 0.5%，高密度区域自适应到 1.5%；行为策略段权重 2×。
- **选择模式**：软选择轮盘赌，适应度 = 0.5×能量 + 0.3×繁殖成功 + 0.2×寿命。
- **事件**：每 500 步随机干旱或丰年；1000 步一次毒雾清除过密区域。
- **输出**：每 50 步记录 CSV 指标，100 步生成热力图快照；终局导出 Parquet 全量日志。

### 8. 进一步拓展建议
- 引入群体结构（族群标签、族群间合作/竞争规则）以研究多层选择。
- 加入遗传漂变、基因驱动、可塑性表型等机制，观察适应性与稳健性。
- 支持 GPU 加速的批量仿真，便于参数搜索与演化对比实验。
